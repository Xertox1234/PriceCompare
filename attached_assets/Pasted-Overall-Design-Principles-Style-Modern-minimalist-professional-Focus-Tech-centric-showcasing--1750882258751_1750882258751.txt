Overall Design Principles
Style: Modern, minimalist, professional.

Focus: Tech-centric, showcasing gadgets and electronics.

Aesthetic: Clean, bright, spacious with intentional whitespace.

User Experience: Seamless navigation, clear calls to action, visually appealing transitions.

🖥 Layout Dimensions
Container & Breakpoints:
Primary Container:

Width: 1280px

Margins: Auto-centered horizontally

Padding: horizontal (24px–32px), vertical (48px–64px)

Responsive Breakpoints:

Mobile: < 768px (Vertical stacks, single column)

Tablet: 768px–1024px (Two-column grids where applicable)

Desktop: > 1024px (max-width 1280px, centered)

🎨 Color Palette
Color	Usage	Hex

Black	Text, Headings	#000000
White	Backgrounds, Cards, Sections	#FFFFFF

Lighter Grey	Borders, Minor Elements	#EAEAEA

🖼️ Images & Assets

Resolution: Minimum 1920px × 700px (aspect ratio approx. 2.7:1).

Style: Bright, tech-centric imagery with dark overlays for contrast.

Dimensions: 400px × 300px

🔘 Buttons & Interactive Elements
Primary Button:

Background: #5A5DFF

Text color: White (#FFFFFF)

Hover state: darken slightly (#4347FF)

Transition: ease-in-out 0.3s

Shadow: subtle shadow (0 4px 12px rgba(0,0,0,0.1))

Secondary Button (outlined):

Background: Transparent, Border 1px solid #EAEAEA

Hover state: border-color darkens, background lightly fills #F7F7F7

📱 Responsiveness
Mobile Optimization:

Stack horizontally aligned content vertically

Font sizes slightly reduced (Heading 1: 32px, Body: 14px)

Padding/Margins adjusted (16px padding standard)

Tablet:

Two-column grid layouts where applicable

Hero text condensed slightly

Desktop:

Original spacing and dimensions as outlined above

🌟 Accessibility (WCAG 2.1 AA Standards)
Text-to-background contrast ratio: minimum 4.5:1

Alt attributes for all images.

Clear focus states for keyboard navigation.

ARIA roles for interactive elements (button, link, navigation).

⚡ Performance Considerations
Image optimization: serve .webp or .avif formats.

Lazy loading for images off viewport.

Minimized CSS & JavaScript bundles.

CDN-delivered static assets.
